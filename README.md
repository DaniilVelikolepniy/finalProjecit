# Сервис бронирования отелей

## 📌 Описание проекта

Учебный проект, выполненный в рамках финальной работы курса **PHP фреймворк Laravel**.  
Сервис представляет собой онлайн-платформу для бронирования отелей.

Администратор управляет отелями, номерами и удобствами через панель управления.  

---

## ⚙️ Технологии

- **PHP:** 8.2  
- **Laravel:** 12.x  
- **База данных:** MySQL  
- **Docker:** Laravel Sail  
- **ORM:** Eloquent  
- **Аутентификация:** встроенная система Laravel (bcrypt для паролей)  
- **Почтовые уведомления:** Laravel Mail  

---

## 🧩 Функционал

### Незарегистрированные пользователи

- Регистрация.  

### Зарегистрированные пользователи

- Авторизация.  
- Просмотр списка отелей.  
- Просмотр карточки отеля и номеров.  
- Бронирование номеров.  
- Просмотр списка собственных бронирований.  
- Отмена бронирований.  
- Получение email-подтверждений.  

### Редактор

- Редактирование и удаление отелей.  
- Создание, редактирование и удаление комнат.  
- Добавление удобств отелю и комнатам.  
- Просмотр пользователей (из числа посетителей отеля) и их бронирований.
- Удаление информации о пользователе.

### Администратор

- Создание, редактирование и удаление отелей.  
- Добавление удобств в приложение.  
- Просмотр всех бронирований и пользователей.
- Управление ролями пользователей.
- Закрепление редактора за отелем.
- Удаление информации о пользователе.

---

## 🖥️ Страницы системы

- `/hotels` — список отелей.  
- `/hotels/{id}` — страница отеля с доступными номерами и формой бронирования.  
- `/bookings` — список бронирований пользователя.  
- `/booking/{id}` — подробности бронирования.  
- `/register` — регистрация.  
- `/login` — авторизация.  

---

## 🗄️ Структура базы данных

Основные таблицы:

- `users` — пользователи.  
- `hotels` — отели.  
- `rooms` — номера.  
- `bookings` — бронирования.  
- `facilities` — удобства.  
- `facility_hotel`, `facility_room` — связи многие-ко-многим.

## 🚀 Установка и запуск

Все команды выполняются в **корне проекта**.

### Создадим файл .env

```bash
cp .env.example .env
```

### Запускаем приложение Docker

- ***На Linux*** ```sudo systemctl start docker```
- ***macOS*** ```open -a Docker```
- ***Windows*** ```Start-Process "<путь_до_директории_с_файлом>/Desktop.exe"```

### Устанавливаем зависимости в проекте

```bash
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    laravelsail/php84-composer:latest \
    composer install --ignore-platform-reqs
```

### Развернём окружение

```bash
./vendor/bin/sail up -d
```

### Сгенерируем ключ приложения

```bash
./vendor/bin/sail artisan key:generate
```

### Выполним миграции

```bash
./vendor/bin/sail artisan migrate
```

### Сидируем базу данных

```bash
./vendor/bin/sail artisan db:seed
```
